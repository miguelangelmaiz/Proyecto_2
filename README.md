Un árbol binario que identifica especies a partir de preguntas utiliza nodos para representar preguntas y hojas para representar especies. El recorrido se puede visualizar en un grafo, mostrando cómo se navega a través de las preguntas hasta llegar a la identificación de una especie específica.
